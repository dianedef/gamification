## 9. Matrice de recommandation par besoin

### « Je commence de zéro en gamification »

```
1. Lire : "Drive" (Pink) → comprendre la motivation
2. Lire : "Hooked" (Eyal) → comprendre les habitudes
3. Cours : "Gamification" sur Coursera (Werbach) → framework complet
4. Outil : Octalysis Tool → analyser ton produit
5. Lire : chapitre 09-Éthique de cette base → garde-fous
```

### « Je veux améliorer la rétention de mon app »

```
1. Lire : "Atomic Habits" (Clear) → formation d'habitudes
2. Lire : "Hooked" (Eyal) → Hook Model
3. Podcast : Huberman Lab (épisodes dopamine) → neurochimie
4. Article : "Does Gamification Work?" (Hamari et al.) → evidence
5. Lire : chapitres 04 + 05 + 07 de cette base → mécaniques + mesure
```

### « Je veux écrire de meilleurs messages gamifiés »

```
1. Lire : "Influence" (Cialdini) → persuasion
2. Lire : "Microcopy: The Complete Guide" (Yifrah) → écriture UX
3. Lire : "Made to Stick" (Heath) → messages mémorables
4. Blog : Growth.Design → études de cas visuelles
5. Lire : chapitre 13 de cette base → copywriting gamifié
```

### « Je m'inquiète de l'éthique de ma gamification »

```
1. Lire : "Indistractable" (Eyal) → l'autre côté de "Hooked"
2. Lire : "Dopamine Nation" (Lembke) → addiction comportementale
3. Conférence : "Gamification is Bullshit" (Bogost) → la critique
4. Lire : "A RECIPE for Meaningful Gamification" (Nicholson)
5. Lire : chapitre 09 de cette base → checklist éthique
```
