# Inspiration — @diane-winflowz/gamification

## Références de gamification

- **Duolingo** — La référence absolue : streaks, XP, leagues, hearts, progression quotidienne. Chaque interaction est gamifiée sans être forcée
- **GitHub Contributions** — Visualisation de streak en heatmap, contribution graph, concept de "green squares" addictif
- **Habitica** — RPG gamification pour habitudes quotidiennes, avatar, quêtes, guildes
- **Khan Academy** — Badges, progression par compétence, energy points, mastery system
- **Stack Overflow** — Réputation, badges (bronze/argent/or), privilèges débloqués par palier

## Fitness et bien-être

- **Fitbit / Apple Watch** — Anneaux d'activité, achievements, streaks, défis entre amis
- **Headspace** — Streaks de méditation, progression douce, félicitations non intrusives
- **Forest App** — Gamification du focus : un arbre qui pousse quand tu restes concentré

## Gaming

- **Xbox Achievements / PlayStation Trophies** — Système de récompenses universel, niveaux de rareté, gamerscore
- **Steam Achievements** — Badges, niveaux, collections, pourcentage de complétion global

## Patterns techniques (npm)

- **vue-confetti** — Animation de confetti réutilisable, bon pattern de composant Vue
- **vue-progressive-image** — Chargement progressif, pattern technique de composant léger

## Points clés à retenir

| Source | Leçon |
|---|---|
| Duolingo | Le streak est le mécanisme d'engagement le plus puissant |
| GitHub | La visualisation de la régularité motive |
| Stack Overflow | Les niveaux de badge (bronze/argent/or) créent de la profondeur |
| Apple Watch | Les micro-célébrations (animations) renforcent le comportement |
| Forest | La simplicité d'un seul mécanisme bien exécuté vaut mieux que dix mal implémentés |
| Habitica | Trop de gamification tue la gamification — trouver le bon dosage |
