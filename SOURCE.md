# Sources — @diane-winflowz/gamification

## Recherche fondamentale

### Frameworks de gamification

- **Yu-kai Chou — Octalysis Framework** : 8 core drives de gamification (accomplishment, empowerment, social influence, unpredictability, avoidance, scarcity, ownership, meaning)
- **Jane McGonigal — Reality is Broken** : comment les mécaniques de jeu peuvent améliorer la vie réelle, engagement volontaire, feedback loops

### Psychologie de la motivation

- **Self-Determination Theory** (Deci & Ryan) : motivation intrinsèque repose sur 3 besoins — autonomie, compétence, relation sociale
- **Flow Theory** (Csikszentmihalyi) : état de flow optimal quand le défi correspond au niveau de compétence
- **Variable Ratio Reinforcement** (Skinner) : les récompenses imprévisibles créent plus d'engagement que les récompenses fixes

## Design patterns de gamification

### Méchaniques classiques (PBL)

- **Points** : mesure de progression, monnaie d'engagement
- **Badges** : reconnaissance visuelle d'accomplissements
- **Leaderboards** : comparaison sociale et compétition

### Patterns avancés

- **Progress bars** : effet Zeigarnik — les tâches incomplètes motivent à finir
- **Loss aversion** : les streaks exploitent la peur de perdre sa série
- **Variable ratio reinforcement schedules** : récompenses à intervalles variables pour maximiser l'engagement
- **Endowed progress effect** : donner une avance initiale augmente la complétion
